# «Конспект» — как продолжить работу

Состояние на 08.10.2026, вечер. Файл для новой сессии Claude: прочитай его целиком, прежде чем что-то менять.

## Что это

Своё бесплатное приложение для конспектов на iPad вместо платного **CollaNote** (с двумя L). Им пользуется Даша, дочь пользователя: школа, курсы Еголенд (сайт pl.el-ed.ru), английский и математика. Интерфейс сделан по её скриншотам CollaNote.

- **Сайт (приложение):** https://centrebolotova.github.io/konspekt/ — на iPad поставлено на экран «Домой».
- **Исходник:** `konspekt.html` (один файл: HTML, CSS, JS).
- **Сборка:** `python build.py` → папка `docs/` (её раздаёт GitHub Pages).
- **Репозиторий:** github.com/centrebolotova/konspekt, ветка `main`, Pages из `/docs`. После правок: сборка → коммит → `git push`. Если Pages долго висит в «building», перезапустить: `gh api -X POST repos/centrebolotova/konspekt/pages/builds`.
- **База и синхронизация:** Supabase, проект `konspekt` (ref `nmyjyuvxiqtvovdectxy`, организация «centrebolotova's Org», бесплатный тариф). Таблицы: `notes`, `assets` (страницы PDF и фото), `inbox` + `inbox_codes` (файлы через «Поделиться»). SQL — в `supabase.sql`. Вход почта + пароль, подтверждение почты выключено. У Даши аккаунт есть, синхронизация работает.

## Что уже сделано

- Главный экран как в CollaNote: «Домой», «Избранное», «Недавние», «Корзина», папки, поиск, сортировка, быстрая заметка, импорт.
- Создание заметки с выбором бумаги: чистая, линейка S/M/L, клетка S/M/L, поля, двойные поля, точки, Корнелл; цвет бумаги.
- Листы бесконечные: в конце всегда есть пустой лист. Масштаб щипком (жесты Safari `gesturestart/change`) и кнопками «− 100% +».
- 13 ручек (без штампов-звёздочек — Даше они не нужны), палитра на 49 цветов, ширина, прозрачность, «красивый почерк» (стабилизатор).
- Фигуры выравниваются сами (только крупные, замкнутые и нарисованные отдельно: штрих сразу после соседнего — это почерк, его не трогаем; 09.10 Даша жаловалась, что «МАМА» превращалась в треугольники — исправлено). Распознавание по выпуклой оболочке: треугольник, четырёхугольник, овал. Фигура рисуется одним движением; любую фигуру можно выровнять, задержав Pencil в конце.
- Палец не рисует после первого касания Pencil (флаг `kp-penseen`). Кнопка с рукой слева включает рисование пальцем.
- Лассо (двигать, копия, цвет, перевести, посчитать, «в текст»), текст, стикеры, фото, маркер, ластик.
- Переводчик: обвести написанное → распознавание почерка (Google inputtools) → перевод (Google Translate, запасной — MyMemory) → озвучка.
- Калькулятор: рукописный ввод и инженерный. Корни, степени и дроби разбираются по расположению штрихов.
- PDF и картинки: перетаскивание из Safari, вставка, импорт. PDF становится листами, на которых можно писать.
- «Поделиться» на iPad: веб-приложение туда не пускают, поэтому сделана Быстрая команда «В Конспект» (инструкция в приложении: облачко слева внизу → «Файлы через «Поделиться»»). Настроила ли её Даша — неизвестно.
- Запись звука с привязкой к записям, таймер, видео/PDF/YouTube рядом с листом, экспорт в PDF и PNG, тёмная тема.
